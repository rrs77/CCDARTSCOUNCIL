00-sitemap — Proposed navigation & teacher journey

Proposed navigation structure

One mental model: set up → plan the year → fill the week → teach. Sidebar groups match that order.

1. Classes

Settings → My classes

2. Timetable

Slots for every class

3. Half-terms

Assign schemes of work

4. Week planner

Fill this week’s lessons

5. Teach

Slides · Export · Share

Plan your year

  • Planner (week / day / timetable)
  • Half-terms (year map + schemes)

Primary weekly home for most teachers.

Build lessons

  • Lesson Builder
  • Lessons (library of saved plans)
  • Activities
  • Slides

Authoring tools; Activities feeds Builder.

Discover & workspace

  • Partner Hubs
  • More: Settings, calendar, help, contact
  • Bolt-ons (Assessify, PeriFeedback)

No duplicate primary tabs in More.

Glossary (teacher-facing)

Activity → building block · Lesson → one session · Scheme of work → sequenced lessons for a half-term · Slide deck → presentable media · Avoid: stack, unit (unless curriculum), Interactive lesson, Lesson Viewer, Karaoke as product names.
