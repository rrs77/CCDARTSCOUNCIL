Proposed navigation structure

Keep one create path. Planner owns the week. Half-terms owns the year. More tools only holds leftovers.

Connect & create

Planner Week Schedule (week/day/month) · Timetable builder · Class calendar
Half-terms Year Year map · Assign scheme · Single-class focus · Progress
Lesson Builder Compose activities into a lesson
Lessons Saved lessons for the selected class
Activity Library Find / create activities for the selected class
Slides Library-first present/edit decks
Partner Hubs Music Hubs map → region → hub · Arts orgs · Paid

Your tools

More tools Settings · Class calendar shortcut · Forum · Contact · Help · Walkthrough
+ Bolt-ons Assessify · PeriFeedback (optional catalogue)

Class context rule

Header class chip on every class-scoped screen Hidden only when explicitly in “All classes” week view
Eyebrows match sidebar section names CONNECT & CREATE / … · YOUR TOOLS / …

Core teacher journey

Setup → plan → teach → share

1. Settings → My classes
↓
2. Planner → Timetable builder
↓
3. Half-terms → assign scheme
↓
4. Activity Library / Lesson Builder
↓
5. Planner week → fill slots
↓
6. Slides → present
↓
7. Lessons → Export PDF / Copy link

Remove Planner “Units” as a third home for half-terms. Remove More tools cards that duplicate sidebar destinations.
