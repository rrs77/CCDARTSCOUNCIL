# My classes — simpler Settings preview

Design-only. One idea: **Settings is just your classes.** Folders are chosen on the class. Partner packs are added in Partner Hubs.

## Open

```bash
cd design/settings-classes-library
python3 -m http.server 8766 --bind 127.0.0.1
```

http://127.0.0.1:8766/

## Model

| Job | Where |
|-----|--------|
| Add / rename / remove a class | Settings → My classes |
| Turn folders on/off for a class | Open that class |
| Create a named folder (Year 7 Drama…) | From inside the class |
| Add arts-org / hub packs | Partner Hubs (then tick on the class) |

No separate Year Groups, Categories, or Activity folders Settings tabs in this preview.
