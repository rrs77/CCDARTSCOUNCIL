Which app uses what

Each app asks only for the data it needs. Permission names are proposed internal names, not provider scopes.

AppData it can receivePermissionNever receives
CCDesignerYear groups only (names, phases, school configuration)year_groups.read⛔ No pupil data of any kind: no names, IDs, classes, parents, attendance, medical or safeguarding
AssessifyPupils, classes, teacher assignmentspupils.read classes.read—
PeriFeedbackPupils, lesson assignments, parent contacts (restricted, only where authorised)pupils.read lesson_assignments.read parent_contacts.read (restricted)—
PeriPlannerPupils, timetables, activities and clubspupils.read timetables.read activities.read—

Access is enforced on the server and in the database, not just hidden on screen.
