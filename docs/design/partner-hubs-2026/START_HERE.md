# Using this CCDesigner Cursor design kit

1. Unzip the folder into your CCDesigner project, ideally `docs/design/partner-hubs-2026/`.
2. Open Cursor at the project root. Attach/reference `CURSOR_PROMPT.md` and all three files in `reference-images/` in your Cursor conversation.
3. Tell Cursor: **“Read and follow the attached CURSOR_PROMPT.md. Inspect the actual codebase and images. Complete Stage 1 and show design previews BEFORE changing the working UI.”**
4. Review the desktop and mobile previews and approve the UX before asking Cursor to implement Stage 2.

The images are screenshots of the current interface provided for critique, **not** an approved target design. The prompt directs Cursor to verify the current Music Hub network and distinguish the official Greater Essex hub from Essex Music Service and the 14 local areas.
